
## 🤖 Trabalhando com Claude

Para melhor colaboração com Claude:

1. **Documentação Local**: Mantenha arquivos importantes localmente e use Git para sincronizar
2. **Sessões Documentadas**: Use `sessoes-claude/` para registrar o que foi feito
3. **Veja o guia completo**: [GUIA-CLAUDE.md](./GUIA-CLAUDE.md)

## 🚀 Como Usar Este Repositório

### Trabalho Local (Recomendado)

```bash
# Clone o repositório
git clone https://github.com/pedrocunha1982/pedrocunha1982.git
cd pedrocunha1982

# Trabalhe localmente
# Claude pode acessar seus arquivos locais diretamente

# Quando quiser salvar no GitHub
git add .
git commit -m "Descrição das mudanças"
git push
```

### Novo Projeto

1. Crie uma pasta em `projetos/seu-projeto`
2. Adicione um README.md no projeto explicando o que é
3. Desenvolva localmente
4. Faça commit quando quiser backup no GitHub

## 📝 Documentar Sessões com Claude

Quando trabalhar com Claude em algo importante:

1. Copie o template: `sessoes-claude/templates/template-sessao.md`
2. Crie um arquivo novo: `sessoes-claude/2026-02-03-nome-da-tarefa.md`
3. Documente o que foi feito

Isso ajuda você a lembrar o que já foi implementado e facilita conversas futuras com Claude.
