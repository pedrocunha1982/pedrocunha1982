# Projetos

Esta pasta contém seus projetos de código.

## 📁 Como Organizar

Cada projeto deve ter sua própria pasta:

```
projetos/
├── projeto-1/
│   ├── README.md
│   ├── src/
│   └── ...
├── projeto-2/
│   ├── README.md
│   └── ...
└── README.md (este arquivo)
```

## 🚀 Criar Novo Projeto

### Opção 1: Pedir ao Claude

```
"Claude, cria um novo projeto Python chamado meu-app em projetos/meu-app
com estrutura básica"
```

### Opção 2: Manualmente

```bash
mkdir projetos/meu-projeto
cd projetos/meu-projeto
# Criar seus arquivos
```

## 💡 Dicas

- Sempre inclua um README.md em cada projeto
- Use .gitignore específico se necessário
- Documente dependências e como executar
- Claude pode ajudar com estrutura inicial

## 📝 Exemplos de Projetos

- `automacao-tarefas/` - Scripts de automação
- `estudos-python/` - Projetos de aprendizado
- `app-web/` - Aplicações web
- `data-analysis/` - Análise de dados
